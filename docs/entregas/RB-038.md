## Objetivo e escopo
Implementação do adaptador de comércio VTEX (`VtexCommerceAdapter`) em TypeScript compatível com a interface unificada `CommerceAdapter` do Boopay. O adaptador implementa:
1. Simulação de carrinho espelhando o contrato VTEX `/api/checkout/pub/orderForms/simulation`, incluindo resolução de SLAs logísticos (PAC/Normal, Sedex/Expressa, Retirada em loja VTEX) e cálculo de totais.
2. Cotação autoritativa vinculada a `quoteHash` determinístico (SHA-256), impedindo flutuações não autorizadas de preço entre a intenção e a finalização.
3. Criação de pedido idempotente, garantindo que retentativas com o mesmo `orderId` não gerem pedidos duplicados na plataforma.
4. Integração nativa na factory `createCommerceAdapter` em `src/commerce/adapter.ts` com fallback gracioso para sandbox/dados locais quando credenciais de produção não estão presentes.

  - Mapeamento determinístico de SLAs de frete VTEX para o padrão interno (`standard`, `express`, `pickup`).
  - Catalog lookup híbrido: suporta itens sincronizados no banco de dados SQLite/Postgres via Prisma (`catalogItem`) com fallback resiliente para catálogo do MVP.

## Como conferir

Certifique-se de que as dependências estão instaladas e o Prisma Client gerado:

```

   npx tsc --noEmit
   ```
3. Verifique o build do frontend Next.js:
   ```bash
   npm run check:web
   ```
