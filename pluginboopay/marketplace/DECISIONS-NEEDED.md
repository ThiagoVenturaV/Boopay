## 2. O vendor opera e é dono do serviço Boopay?

- Resposta:
- Se não, qual empresa opera o serviço?
- Existe autorização formal para desenvolver, cobrar, suportar e representar a integração?

A Woo prefere integrações first-party; uma relação de terceiros deve ser explicada antecipadamente.

## 3. Qual rota de monetização será usada?

Escolha uma:

- Billing API — recomendada para a Woo administrar a assinatura do SaaS.
- Partnership Agreement — plugin gratuito e cobrança externa, sujeito à aprovação da Woo.

O modelo normal de plugin pago não serve para um SaaS faturado externamente.
